# 职达 TalentPath 使用手册

本文档用于本地演示和验收，重点说明三端如何进入、如何跑通完整流程。

## 1. 启动系统

在项目根目录执行：

```bash
docker compose up -d --build
docker compose ps
curl http://localhost:8000/api/health
```

启动成功后访问：

- 前端：http://localhost
- 后端 API：http://localhost:8000
- Swagger 文档：http://localhost:8000/docs

如需启用 AI 功能，在根目录创建 `.env` 文件并配置大模型密钥：

```env
LLM_API_KEY=your_api_key
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-4o-mini
```

配置后重启容器即可生效。没有密钥时系统仍可运行，但 AI 诊断、审核、复评等功能不可用。

## 2. 演示数据

系统首次启动时自动初始化种子数据，包括：

- 8 家企业（6 家正常、1 家待审核、1 家已禁用）
- 10 个岗位（9 个已发布、1 个待审核）
- 8 个岗位能力模型（含技术技能、软技能、领域知识、项目经验和权重配置）

种子数据幂等，重启不会重复创建。学生数据需通过前端注册创建。

如需重置全部数据：

```bash
docker compose down
docker volume rm agent_talent_path_data
docker compose up -d --build
```

## 3. 首页入口

首页是统一登录界面，提供三个入口：

- 学生端
- 企业端
- 学校端

学生登录区下方有"新用户"入口，可从空白档案开始体验。

当前版本保留密码框，但不做真实密码校验，只用于区分角色和用户，方便后续扩展。

## 5. 学生端流程

### 5.1 新用户流程

1. 在首页选择学生端。
2. 点击"新用户"。
3. 填写基本信息（姓名、学校、专业、年级、目标岗位）。
4. 填写技术技能（支持添加多项技能并设置熟练度）。
5. 填写项目经历（项目名称、角色、描述、时长）。
6. 填写学业基础（GPA、排名、核心课程成绩、获奖与竞赛）。
7. 填写软技能证据（团队协作、沟通表达、主动性，附具体事例）。
8. 可选择上传简历文件，系统调用 AI 自动解析并填充对应字段（LLM 解析超时放宽至 5 分钟）。
9. 可选择上传成绩单（仅作为授权后企业查看材料，不做自动识别）。
10. 保存档案后自动进入诊断流程。

核心字段应保证足够支撑 AI 诊断，包括基本信息、教育经历、求职意向、技能、项目经历等。非核心字段可以为空。

### 5.2 诊断流程

保存档案后系统自动触发 AI 诊断，通过 SSE 流式展示五个阶段的进度：

1. 数据采集 — 读取教育背景、技能经历和项目经验
2. 能力分析 — AI 多维度评估核心竞争力
3. 岗位匹配 — 基于能力画像匹配最适合的职业方向
4. 路径规划 — 生成个性化成长路线图
5. 生成建议 — 整合分析结果，输出完整诊断报告

信息不完整时，智能体会返回追问，列出缺失字段和优先级，不会强行生成低质量诊断。

### 5.3 诊断结果看板

诊断完成后进入四标签看板：

**成长总览**
- 能力画像雷达图（五维：技术技能、项目经验、学业基础、领域认知、软技能证据）
- 五维分值卡片（百分比显示，含版本间变化值）
- 技能标签云（按维度着色，分值越高越醒目）
- 学业基础详情（GPA、排名、核心课程、获奖证书）
- 软技能证据支撑（强/中/弱评级，附具体事例）
- 成长趋势折线图（多版本对比）

**诊断解释**
- 综合匹配度仪表盘（ECharts 仪表盘，含上次对比）
- 匹配分公式解释面板（权重分配、计算方式、置信度）
- 五维匹配度卡片（各维度分数 + 证据状态）
- TOP5 匹配岗位排行（匹配度进度条、已匹配/缺失技能标签）
- 差距分析柱状图（已全面中文化：维度标签、提示框、坐标轴标签）

**成长任务**
- 分阶段成长路径时间线
- 每个阶段的具体任务卡片（名称、描述、预期影响、所需资源）
- 提交证据面板
- AI 审核结果面板（通过/未通过 + 评分 + 反馈）
- 复评确认面板
- 复评进度面板

**岗位授权**
- 三级优先级分组展示可授权岗位（当前诊断目标岗位 > 诊断推荐岗位 > 其他可授权岗位）
- "一键授权全部推荐岗位"按钮，支持批量授权
- 选择企业并授权查看
- 查看已授权企业列表
- 撤销授权

**其他功能**
- 右下角悬浮 AI 助手按钮（自然语言对话）
- 导出工具栏（PDF / Excel 格式诊断报告，单次最多导出 200 条记录）
- 重新诊断按钮（顶部栏，基于当前数据重新评估）

## 6. 企业端流程

### 6.1 门禁验证

1. 使用企业 ID `4` 登录。
2. 系统应提示企业已被禁用，不能进入企业后台。
3. 待审核企业（ID `3`）同样会被拦截。

### 6.2 正常企业流程

1. 使用企业 ID `1` 登录。
2. 查看岗位列表（含状态标签：已发布 / 待审核 / 已下线）。
3. 创建新岗位。
4. 填写岗位名称、招聘描述与技能要求。
5. 点击解析岗位能力模型（AI 自动从描述中提取技术技能、软技能、领域知识等维度的目标分值）。
6. 提交学校审核。
7. 查看岗位审核状态和驳回原因。
8. 进入候选人视图，岗位卡片显示匹配统计 badge（"已授权 X / 潜在匹配 Y"），帮助企业了解人才池规模（仅匿名计数，保护隐私）。
9. 选择岗位后查看已授权候选人。
10. 打开候选人详情，查看能力画像、匹配分、优势、差距和证明材料。若学生授权后进行了复评，系统自动展示最新诊断版本（标注"已复评，以下为最新数据"）。
11. 右上角可退出登录。

企业端核心是岗位和候选人，不做复杂企业主页。授权后诊断数据自动同步最新版本，企业始终看到学生最新能力画像。

## 7. 学校端流程

1. 使用 `admin` 登录。
2. 查看概览面板（增强统计卡片：学生总数、已评测数、未评测数、平均匹配分、企业数、已审核岗位、待审核岗位、活跃授权数），点击卡片可跳转到对应管理页面。
3. 进入学生管理，支持按诊断状态筛选（全部 / 已评测 / 未评测），快速定位未评测学生。
4. 点击学生查看诊断详情：能力雷达图、差距柱状图（中文化）、AI 成长建议、TOP5 匹配岗位、附件材料、成长任务完成汇总。
5. 在学生详情中，点击"推荐到企业"按钮，将学生推荐给匹配岗位的企业（管理员发起授权，无需学生操作）。
6. 进入企业管理，查看企业状态。
7. 启用或禁用企业。
8. 进入岗位审核。
9. 查看企业提交的岗位招聘要求描述和能力模型。
10. 审核通过岗位，学生端即可匹配到该岗位。
11. 驳回岗位并填写原因，企业端可查看驳回原因。
12. 右上角可退出登录。

学校端定位为后台管理，不承担复杂培养任务设计。培养建议和成长任务主要交给智能体。管理员推荐功能在尊重隐私的前提下，打通学生与企业间的双向连接。

## 8. 验收重点

完整演示时优先确认以下链路：

```text
学生创建档案
  -> AI 判断信息完整度
  -> AI 诊断（SSE 流式进度）
  -> 岗位匹配（TOP5 + 差距分析，图表中文化）
  -> 成长任务（分阶段路径）
  -> 证据提交
  -> AI 审核
  -> 复评（版本对比）
  -> 学生一键批量授权
  -> 企业按岗位查看候选人（自动展示最新诊断版本，显示潜在匹配计数）
  -> 企业端回看（授权版本自动同步）
  -> 学校按诊断状态筛选学生
  -> 学校查看学生诊断详情（雷达图 + 差距图）
  -> 学校管理员推荐学生到企业
  -> 学校审核企业和岗位
```

只要该链路能稳定走通，项目核心目标即成立。界面细节、动画等不属于当前阶段的阻断项。
