# 职达 TalentPath 演示流程

更新时间：2026-06-11

本文档用于比赛、答辩或本地验收时快速跑通三端闭环。

## 1. 准备环境

```bash
docker compose up -d --build
docker compose ps
curl http://localhost:8000/api/health
```

健康检查应返回 `"ai_status": "configured"` 和 `"ai_available": true`。如果显示 `missing_key`，请在 `.env` 中配置 `LLM_API_KEY`。

访问前端：

```text
http://localhost
```

系统首次启动时自动初始化 8 家企业和 10 个岗位种子数据，无需额外操作。

## 2. 推荐演示顺序

建议按照"学校端 -> 企业端 -> 学生端 -> 企业端回看"的顺序演示，逻辑更清晰。

```text
学校审核企业和岗位
  -> 企业发布岗位
  -> 学生诊断和授权
  -> 企业按岗位查看候选人
```

## 3. 学校端演示

账号：`admin`

演示点：

1. 进入学校端。
2. 查看概览面板的增强统计卡片（学生总数、已评测数、平均匹配分、企业数、已审核岗位、待审核岗位、活跃授权数），点击卡片可跳转到对应管理页面。
3. 进入企业管理，确认正常企业（字节跳动、华为技术、腾讯科技等）和禁用企业（已禁用公司）状态。
4. 进入学生管理，演示按诊断状态筛选（全部 / 已评测 / 未评测），快速定位未评测学生。
5. 点击学生查看详情：能力雷达图、差距柱状图、AI 成长建议、TOP5 匹配岗位、附件材料、成长任务汇总。
6. 在学生详情中，点击"推荐到企业"按钮，将学生推荐给匹配岗位的企业（管理员发起授权）。
7. 进入岗位审核。
8. 查看待审核岗位的招聘要求描述和能力模型。
9. 审核通过一个岗位。
10. 驳回一个岗位并填写原因。
11. 点击右上角"退出"按钮可登出。

要说明的产品逻辑：

- 学校端是后台管理，不是培养任务制定方。
- 学校主要保证企业和岗位质量，同时作为人才推荐枢纽可主动推荐学生给企业。
- 学生培养建议由智能体根据档案、岗位和成长记录生成。
- 管理员推荐功能在尊重隐私的前提下，帮助打通学生与企业的双向连接。

## 4. 企业端演示

正常企业账号：`1`（字节跳动）

禁用企业账号：`4`（已禁用公司）

演示点：

1. 使用企业 ID `4` 登录，展示禁用企业拦截（系统提示"该企业已被禁用"）。
2. 使用企业 ID `1` 登录。
3. 查看岗位列表（包含已发布、待审核、已下线等状态标签）。
4. 创建或打开一个岗位。
5. 填写招聘描述与技能要求，点击解析岗位能力模型。
6. 提交学校审核。
7. 查看被驳回岗位的驳回原因。
8. 进入候选人视图。
9. 查看岗位卡片上的匹配统计 badge："已授权 X / 潜在匹配 Y"，展示企业可感知匹配但未授权的人才规模（仅匿名计数，保护隐私）。
10. 选择岗位后查看已授权候选人。
11. 打开候选人详情，查看画像、匹配分、优势、差距和材料。注意展示"最新诊断版本"标注——若学生授权后进行了复评，企业端自动同步展示最新诊断数据。
12. 点击右上角"退出"按钮可登出。

要说明的产品逻辑：

- 企业端不做复杂企业主页，核心是岗位和候选人。
- 候选人推荐必须基于岗位，否则匹配没有业务上下文。
- 企业只能看到学生主动授权后的信息。潜在匹配计数帮助企业了解人才池规模，但不能查看未授权学生的身份。
- 授权后企业看到的诊断数据自动保持最新（学生复评后同步更新），无需重新授权。

## 5. 学生端演示

### 5.1 新用户完整流程

1. 在首页选择学生端。
2. 点击"新用户"。
3. 填写基本信息（姓名、学校、专业、年级、目标岗位）。
4. 填写教育背景、技能清单、项目经历。
5. 可选择上传简历文件（PDF / DOCX / TXT），系统调用 AI 自动解析并填充字段。
6. 可选择上传成绩单（仅作为授权后企业查看材料）。
7. 保存档案。
8. 系统自动触发 AI 诊断（SSE 流式进度：数据采集 -> 能力分析 -> 岗位匹配 -> 路径规划 -> 生成建议）。
9. 诊断完成后进入看板。

### 5.2 完整成长闭环（诊断后）

1. 查看成长总览（能力画像雷达图、五维分值卡片、技能标签云）。
2. 切换到"诊断解释"标签，查看岗位匹配分析（综合匹配度仪表盘、五维匹配度卡片、TOP5 匹配岗位、差距分析柱状图——图表已全面中文化）。
3. 查看匹配分计算说明和置信度。
4. 切换到"成长任务"标签，查看分阶段成长路径和具体任务。
5. 选择任务并提交证据。
6. AI 审核证据（实时展示审核结果面板）。
7. 审核通过后弹出复评确认。
8. 触发复评（SSE 流式进度）。
9. 查看新旧诊断版本对比（成长趋势折线图、版本间能力变化表）。
10. 切换到"岗位授权"标签，演示三级优先级分组（当前诊断目标岗位 > 诊断推荐岗位 > 其他岗位），点击"一键授权全部推荐岗位"进行批量授权。
11. 点击右下角悬浮按钮可与 AI 助手对话。
12. 使用导出工具栏可导出诊断报告（PDF / Excel，单次最多 200 条记录）。

要说明的产品逻辑：

- 学生端是项目重点。
- 智能体不只是问答，而是参与诊断、任务、审核、复评的完整链路。
- 成绩单只作为材料给企业查看，不做自动识别，避免过度设计。
- 信息不完整时智能体会追问缺失字段，不会强行生成低质量诊断。
- 批量授权降低操作成本，三级优先级分组帮助学生聚焦最匹配的岗位。

## 6. 企业端回看候选人

1. 回到企业端。
2. 使用企业 ID `1` 登录。
3. 选择一个岗位。
4. 查看刚才授权的学生候选人。
5. 打开候选人详情。
6. 展示学生画像、匹配分、优势、差距、证明材料。若学生在授权后进行了复评，系统自动展示最新诊断版本（标注"已复评，以下为最新数据"）。

这是完整闭环的最后一步：学生授权后，企业能在具体岗位上下文中查看候选人。授权版本自动同步确保企业始终看到学生最新的能力画像。

## 7. 验收标准

演示通过的最低标准：

- 三端都能登录。
- 学校能审核企业和岗位。
- 学校能按诊断状态筛选学生、查看学生诊断详情（雷达图 + 差距图）、推荐学生到企业。
- 企业能维护岗位并查看授权候选人（含潜在匹配计数和最新诊断版本自动同步）。
- 学生能创建或维护档案。
- 智能体能判断信息完整度。
- 完整学生能完成诊断、任务、证据审核、复评和授权（含一键批量授权）。
- 企业能在授权后看到候选人详情（自动展示最新诊断版本）。

以下问题暂不作为阻断：

- 页面动效和视觉精修。
- 大数据量分页体验。
- 聊天历史刷新恢复。
- 企业通知中心。
- 响应式布局适配。
